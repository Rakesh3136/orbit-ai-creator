# AIMN Web Command Center

Responsive Next.js interface foundation for mobile and desktop.

## Local setup

```bash
cd apps/web
npm install
npm run dev
```

Open http://localhost:3000.

The current overview is a UI shell. It deliberately displays integration states rather than fabricated channel counts, agent activity, or AI responses. Chat, authentication, channel management, and live data will be enabled as their backend services are implemented and tested.
