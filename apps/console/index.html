Connect this console to your GitHub repository, choose an agent permission profile, and launch bounded AIMN jobs from your phone.

Important: this GitHub-only edition runs finite GitHub Actions jobs. It is not an always-on server. The current runner creates plans; it does not yet perform live research, model inference, YouTube uploads, or autonomous publishing.

Create a fine-grained token for this repository only. Minimum permissions: Actions — Read and write; Contents — Read-only. The token is kept in page memory only and is not saved to browser storage. Disconnect or close the page to clear it. Never use a classic all-repositories token.

Permission boundaries

  • No profile grants literal unlimited access or changes GitHub token scopes.
  • Publishing, messaging, spending, account changes, OAuth grants, and destructive actions require separate owner approval.
  • The runner currently has no YouTube credentials and cannot publish videos.
  • Do not put secrets in task instructions. Disconnect when finished on a shared device.

The selected profile is an application policy, not a grant of additional GitHub permissions. GitHub Actions permissions are separately limited in the workflow file.
